# 06_Documentation

Living documentation for Velnix, distinct from the Phase 1 planning
artifacts in `00_Project_Constitution/`, `04_Architecture/`, and
`05_UI_UX/`.

## Progress_Reports/

Home for reports generated by the "Okay-Great-Pack" command (referenced
in `Coding_Standards.md` § Code Review, tying PR review to progress
tracking). Suggested naming convention:

```
Progress_Reports/YYYY-MM-DD_Phase<N>_<short-slug>.md
```

Each report should cover, at minimum:
- What shipped since the last report
- Dependencies added (cross-check against the Licensing & Linking Policy
  in the Constitution before merging any PR that adds one)
- Tests added/updated
- Any Definition of Done exceptions and why

## Other subfolders

Add subfolders here as documentation needs emerge — e.g. user-facing
docs, API/IPC boundary docs for the Plugin system (Phase 6+), and
release notes per the Release Strategy in the Constitution.
